# Occupancy Heatmap Card

A compact Home Assistant heatmap that shows how long a numeric or categorical entity occupied each hour.

> The first public release is under active development. The default branch contains a loadable development build.

## Development

```bash
npm install
npm test
npm run build
```

See the design and implementation records in [`docs/superpowers`](docs/superpowers).
